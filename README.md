🌍 Travel Dashboard

A Python command-line application that provides useful information about a destination, including its current weather, country details, languages, local time, and currency exchange rate.

The project integrates multiple public APIs to retrieve real-time information and demonstrates practical Python skills such as API integration, JSON processing, exception handling, logging, type hints, and automated testing with pytest.

✨ Features

Location Search: Search for a destination by name and retrieve its country, country code, and geographic coordinates.

Weather Information: Retrieve the current temperature and weather condition for the selected destination.

Country Information: Display the country's region, official language information, and currency details.

Currency Exchange Rate: Retrieve the exchange rate from USD to the destination's currency.

Timezone Information: Use the destination's timezone and local time provided by the weather API.

Error Handling: Handle common API failures, including timeouts, connection errors, HTTP errors, and invalid JSON responses.

Logging: Record relevant application events and errors in travel.log.

Automated Testing: Use pytest and mocks to test functions without making real API requests.
